Calcul d'adresses IP

Méthode complète : lire un masque, calculer l'adresse réseau, le broadcast, la plage d'hôtes, et découper en sous-réseaux.

📌 Rappels essentiels

Une adresse IP est composée de 4 octets (32 bits). Elle se note en décimal pointé : 192.168.1.0. Le masque de sous-réseau définit la partie réseau (bits à 1) et la partie hôte (bits à 0).

Exemple — IP : 192.168.1.0 / Masque : /24 = 255.255.255.0
11000000. 10101000. 00000001. 00000000
Bits réseau (24 bits)    Bits hôte (8 bits)
Nombre d'hôtes utilisables = 2n − 2    (n = nb de bits hôte)
− 2 car : adresse réseau (tous bits hôte à 0) + broadcast (tous bits hôte à 1)

🔢 Méthode en 5 étapes — À partir d'une IP + masque

1
Identifier le nombre de bits hôte
Masque /24 → 32 − 24 = 8 bits hôte. Masque /26 → 32 − 26 = 6 bits hôte.
2
Calculer l'adresse réseau (AND bit à bit entre l'IP et le masque)
Méthode rapide : les octets couverts par des 255 restent identiques. L'octet partiel se calcule. Les octets à 0 deviennent 0.
3
Calculer le broadcast
Reprendre l'adresse réseau, mettre tous les bits hôte à 1 (= remplacer les 0 du masque par des 255 dans l'adresse réseau).
4
Calculer la plage d'hôtes utilisables
Premier hôte = adresse réseau + 1. Dernier hôte = broadcast − 1.
5
Calculer le nombre d'hôtes
2n − 2 (n = bits hôte)
Exemple A — IP : 192.168.10.50 / Masque : /24 (255.255.255.0)
Bits hôte : 32 − 24 = 8 bits
Adresse réseau  : 192.168.10.0
Broadcast        : 192.168.10.255
Premier hôte    : 192.168.10.1
Dernier hôte    : 192.168.10.254
Nb d'hôtes      : 28 − 2 = 254 hôtes
Exemple B — IP : 10.0.5.130 / Masque : /26 (255.255.255.192)
Bits hôte : 32 − 26 = 6 bits
Masque dernier octet : 11000000 = 192
  → Bloc de taille 26 = 64. Les blocs sont : 0, 64, 128, 192...
  → 130 est dans le bloc qui commence à 128
Adresse réseau  : 10.0.5.128
Broadcast        : 10.0.5.191 (128 + 64 − 1)
Premier hôte    : 10.0.5.129
Dernier hôte    : 10.0.5.190
Nb d'hôtes      : 26 − 2 = 62 hôtes
Pour un /26, la taille du bloc est 64. Pour /27 → 32. Pour /28 → 16. Pour /29 → 8. Pour /30 → 4 (2 hôtes utilisables — lien point à point).

⚡ Astuce — Taille de bloc (méthode rapide)

La taille de bloc = 256 − valeur du dernier octet du masque.

Masque 255.255.255.0   → bloc = 256 − 0 = 256 (tout un /24)
Masque 255.255.255.128 → bloc = 256 − 128 = 128 (/25)
Masque 255.255.255.192 → bloc = 256 − 192 = 64  (/26)
Masque 255.255.255.224 → bloc = 256 − 224 = 32  (/27)
Masque 255.255.255.240 → bloc = 256 − 240 = 16  (/28)
Masque 255.255.255.248 → bloc = 256 − 248 = 8   (/29)
Masque 255.255.255.252 → bloc = 256 − 252 = 4   (/30)

Ensuite les blocs se succèdent : 0, 64, 128, 192... (pour /26). L'adresse IP appartient au bloc dont le début est le multiple de la taille de bloc immédiatement inférieur ou égal à l'IP.

✂️ Découper un réseau en sous-réseaux (VLSM)

Le VLSM (Variable Length Subnet Mask) permet de créer des sous-réseaux de tailles différentes depuis un réseau de départ. Méthode :

Étape 1 — Trier les besoins du plus grand au plus petit
Toujours allouer d'abord le plus grand sous-réseau pour éviter le gaspillage d'adresses.
Étape 2 — Trouver le masque adapté à chaque besoin
Besoin de 50 hôtes → 2n ≥ 52 (50+2) → n=6 → /26. Besoin de 10 hôtes → 2n ≥ 12 → n=4 → /28.
Étape 3 — Allouer en séquence à partir de l'adresse de départ
Chaque sous-réseau commence là où le précédent s'arrête (broadcast + 1).
Exemple VLSM — Réseau de départ : 192.168.1.0/24 — Besoins : 60 hôtes, 28 hôtes, 12 hôtes, lien P2P
Sous-réseau 1 : 60 hôtes → /26 (62 utiles)
  Réseau : 192.168.1.0/26 — Hôtes : .1 → .62 — Broadcast : .63

Sous-réseau 2 : 28 hôtes → /27 (30 utiles)
  Réseau : 192.168.1.64/27 — Hôtes : .65 → .94 — Broadcast : .95

Sous-réseau 3 : 12 hôtes → /28 (14 utiles)
  Réseau : 192.168.1.96/28 — Hôtes : .97 → .110 — Broadcast : .111

Lien P2P : 2 hôtes → /30 (2 utiles)
  Réseau : 192.168.1.112/30 — Hôtes : .113 → .114 — Broadcast : .115

🔄 Conversion rapide — Binaire ↔ Décimal

Valeurs des 8 bits d'un octet (de gauche à droite) :

Bit 7 : 128    Bit 6 : 64    Bit 5 : 32    Bit 4 : 16
Bit 3 : 8      Bit 2 : 4     Bit 1 : 2     Bit 0 : 1
Exemples
11111111 = 128+64+32+16+8+4+2+1 = 255 (masque complet)
11000000 = 128+64                  = 192 (masque /26)
11100000 = 128+64+32             = 224 (masque /27)
10000010 = 128+2                  = 130 (adresse hôte)
Pour convertir un décimal en binaire : diviser par 2 et noter les restes de bas en haut. Ou : soustraire les puissances de 2 (128, 64, 32…) dans l'ordre, mettre 1 si possible, 0 sinon.

📌 Récap à mémoriser

Adresse réseau    = IP AND Masque
Broadcast         = Réseau + (taille bloc − 1)
Premier hôte      = Réseau + 1
Dernier hôte       = Broadcast − 1
Nb hôtes utiles    = 2n − 2  (n = bits hôte)
Taille de bloc     = 256 − dernier octet du masque
Nb de sous-réseaux = 2s    (s = bits empruntés)
